Go 语言最佳实践

1. 错误处理
   始终检查错误返回值。不要忽略错误。使用 errors.Is 和 errors.As 进行错误判断。
   对于预期的错误，返回明确的错误信息；对于意外的错误，添加足够上下文。

2. 并发模式
   使用 Goroutine 进行并发操作时，始终使用 WaitGroup 或 Channel 同步。
   避免 Goroutine 泄漏，确保每个启动的 Goroutine 都有退出路径。
   对于有界的并发，使用带缓冲的 Channel 作为信号量。

3. 接口设计
   接口应该小而专注。遵循 "accept interfaces, return structs" 原则。
   不要为了测试而创建不必要的接口。只在需要多种实现时才定义接口。

4. 上下文使用
   函数接收 context.Context 作为第一个参数，便于传递超时和取消信号。
   不要在结构体中存储 Context。始终检查 ctx.Err() 确认取消状态。

5. 内存管理
   Go 的垃圾回收器会自动管理内存，但好的实践仍然重要。
   避免循环引用导致的内存泄漏。对于大对象，使用 sync.Pool 复用。

6. 日志记录
   使用结构化日志而不是 Println。记录关键信息的同时避免敏感数据。
   在生产环境中使用日志级别控制（DEBUG, INFO, WARN, ERROR）。
